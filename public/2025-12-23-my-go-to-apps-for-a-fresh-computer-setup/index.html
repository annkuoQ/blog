最近買了新筆電
因為舊的用了五年
怕某天掛掉
而且 Win10 也不能更新了

總之這篇就是紀錄一下
一台新電腦要安裝哪些軟體

開發與程式

  • Git: 版本控制
  • Google Cloud CLI: GCP 命令列管理工具
  • Node.js: JavaScript 執行環境
  • Python: 通用程式語言
  • Postman: API 測試工具

文字編輯器

  • Visual Studio Code (可以一邊寫程式，一邊使用終端機)
  • Notepad++ (取代內建記事本)

瀏覽器

  • Google Chrome
  • Firefox

遠端連線

  • Chrome Remote Desktop
  • Ivanti Secure Access Client

通訊聯繫

  • Slack
  • LINE

影音處理

  • OBS: 串流與錄影
  • ffmpeg: 影音轉檔
  • yt-dlp: 影音下載
  • SubtitleEdit: 字幕編輯
  • MediaInfo: 影音檔案資訊查看
  • Captura: 螢幕錄影 (雖然已停止維護，但還是可以用)

影音播放器

  • VLC media player
  • PotPlayer
  • Sony XDCAM Viewer: 專用於播放 MXF

系統監測

  • TreeSize: 磁碟空間分析 (一眼看出哪些資料夾或檔案佔最多空間)
  • HWiNFO: 硬體資訊監控
  • PowerToys: 微軟官方工具集 (很多實用小工具)

文書與檔案管理

  • 7-Zip: 壓縮／解壓縮 (WinRAR 不是付費軟體XD)
  • PDFsam: PDF 分割與合併 (把文件上傳到 iLovePDF 也是怕怕的)
  • PDF 轉向小工具: PDF 頁面旋轉

開源字型

  • 思源黑體
  • 思源宋體
  • jf open 粉圓
  • 芫荽

最後來抱怨一下

現在鍵盤右邊的 Ctrl 都被改成 Copilot
嘗試了 各種方式 都沒辦法改回來
原本習慣右手 Ctrl +/- 縮放畫面
還有 Ctrl + , 打出逗號
最後只好把右邊的 Alt 改成 Ctrl
Copilot 直接設定不作用

再來是 Win11 太多版位有不相干的資訊了
登入畫面有新聞跟天氣
工具列也有天氣
開始功能表、搜尋、通知都有推薦軟體
還一直跳 OneDrive 通知
只能一個一個慢慢去設定裡關掉

雖然抱怨了一番
但還是期待新電腦的陪伴
從今天開始就多多指教
希望能一起走很久 💪
