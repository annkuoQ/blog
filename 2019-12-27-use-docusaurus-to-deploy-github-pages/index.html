    用 Docusaurus 和 GitHub Pages 架網站

    Docusaurus 是 Facebook 團隊的開源作品，可以輕鬆產生靜態網站，適合用於 Documentation Website，在開始前要安裝 git 和 node.js，並創建一個 repo ...

    2019-12-27

    為什麼要用 Docusaurus？

    • 因為工程師朋友推薦
    • 因為 Slash (恐龍吉祥物) 很可愛
    • 因為是 Facebook 團隊的開源作品很酷
